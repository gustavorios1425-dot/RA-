# Quetzalcoatl - Sistema de Gestión de Aerolínea

Proyecto académico desarrollado con arquitectura basada en servicios, frontend interactivo y un entorno de desarrollo contenedorizado para la gestión de vuelos y reservas.

## 🚀 Características del Proyecto

* **Interfaz Web (Frontend):** Diseño responsivo e intuitivo para la navegación de los usuarios, consulta de vuelos y simulación de flujos de autenticación.
* **Entorno Local (Backend y Base de Datos):** Configuración completa con **Docker, PHP y MySQL** para la lógica del servidor y persistencia de datos de forma local.
* **Despliegue Estático:** Interfaz pública optimizada y alojada en **GitHub Pages** para la visualización rápida del diseño y la experiencia de usuario.

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript.
* **Backend y Base de Datos:** PHP, MySQL.
* **Contenedorización:** Docker, Docker Compose.
* **Control de Versiones y Despliegue:** Git, GitHub, GitHub Pages.

## 📂 Estructura del Repositorio

* `main` (Rama principal): Contiene el código fuente completo del entorno de desarrollo local con soporte para Docker, PHP y MySQL.
* `web` (Rama de despliegue): Contiene los archivos estáticos adaptados para la visualización del diseño de la interfaz a través de GitHub Pages.
